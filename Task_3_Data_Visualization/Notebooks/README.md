# Data Visualization — Superstore Sales

## Project Overview

This project focuses on analyzing and visualizing sales data from the Tableau Superstore dataset using Python.

The goal is to create clear and meaningful visualizations that help understand sales and profit patterns across different categories, regions, segments, and sub-categories.

## Dataset

The dataset used in this project is the Tableau Sample Superstore dataset.

- Rows: 10,194
- Columns: 21
- File: `sample_-_superstore.xls`

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations Created

1. Sales by Category
2. Profit by Category
3. Sales by Region
4. Monthly Sales Trend
5. Top 10 Sub-Categories by Sales
6. Sales by Segment
7. Profit by Region
